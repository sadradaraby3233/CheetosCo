CheetosCo — Changelog
=====================

Version 2.0.1
  - Fixed "right on top of you" false positive: thresholds lowered to 0.3
    so direction is described even when the target is close but not on top of you.
  - Fixed tracking lag: beacon now uses lightweight 'equalpower' panner instead
    of HRTF to reduce CPU load during repeated beeps.
  - HRTF is still used for one-off spatial sounds.

Version 2.0.0
  - Returned to JavaScript! Full rewrite back to the web stack.
  - Restored: radio button widget, settings categories, chiptune menu music,
    music fading, HRTF 3D audio via Web Audio PannerNode.
  - Kept all fixes: raw dx/dy direction system, zone auto-announce,
    radar lock-on, beacon with HRTF spatialization.
  - Removed all Python files.
  - Escape on main menu exits the app.

Version 1.2.0
  - COMPLETELY rewrote direction system. No more angle/atan2 confusion.
    Now uses raw dx/dy to build descriptions like "in front and slightly to the left".
  - Direction is now 100% consistent: dx>0 = right, dx<0 = left, dy<0 = in front, dy>0 = behind.
  - Beacon panning uses dx/dist for accurate left/right stereo placement.
  - Escape on main menu now exits the game.
  - Zone auto-announce on movement.
  - Radar lock-on triggers when target is roughly centered ahead.

Version 1.1.1
  - Fixed NPC spawning inside the reception desk (moved desk and NPC apart).
  - Fixed zone labels: north/south were swapped in the map file.
  - Zone changes now auto-announce when you walk into a new zone.
  - Initial zone is set silently on world entry to avoid double-announcement.

Version 1.1.0
  - FIXED direction system: removed facing entirely. Direction is now pure dx/dy.
    Left is ALWAYS left, right is ALWAYS right. No more confusion.
  - Added radar lock-on sound: when a tracked target is straight in front,
    a rising chirp plays to signal you are aligned.
  - Better direction descriptions: "in front and slightly to the left",
    "directly to your right", etc.
  - Beacon panning now uses simple angle/90 mapping. Correct left/right.
  - Rewrote audio with proper sweep generation for beacon and lockon.

Version 1.0.3
  - Rewrote audio engine with stereo sound generation.
  - Implemented constant-power panning without DLL dependencies.
  - Added interaural time delay (ITD) for spatial audio.

Version 1.0.2
  - Fixed accessible_output2 import path (accessible_output2.outputs.auto.Auto).

Version 1.0.1
  - Removed all legacy JavaScript and HTML files.
  - Project is now purely Python-based.
  - Kept maps/reception.map as it is still used by the Python engine.

Version 1.0.0
  - Complete rewrite in Python using Pygame for keyboard input.
  - Uses accessible_output2 (output.auto.auto) for screen reader speech.
  - Borderless, invisible Pygame window captures keyboard only.
  - Full menu system with stack-based navigation.
  - Data-driven map engine with zones, objects, collision, and tracking.
  - Beacon tracking system with T/W/B commands.
  - Procedural audio for footsteps, beeps, and menu sounds.

Version 0.3.1
  - Rewrote HRTF 3D audio with correct coordinate mapping (game X/Y/Z to audio X/Z/Y).
  - Fixed beaconBeep to actually produce sound when position is valid.
  - Fixed direction calculation using proper atan2 with north-axis reference.
  - Simplified and stabilized tracking menu state transitions.
  - Added legacy Web Audio API fallback for older browsers.

Version 0.3.0
  - Implemented HRTF-based 3D audio system using Web Audio API PannerNode.
  - Beacon beeps now use true 3D spatialization - you can hear the direction the sound is coming from.
  - Fixed direction calculation: now properly accounts for player facing direction.
  - Fixed tracking menu stack bug: pressing Escape now properly returns to world mode.
  - Added listener position updates so 3D audio works correctly as you move.

Version 0.2.1
  - Fixed critical bug: tracking menu now properly switches between world and menu controls.
  - The menu no longer stacks up when pressing Escape while in the tracking menu.

Version 0.2.0
  - Added interactive tracking beacon system.
  - Press T to open a menu of trackable objects. Selecting one locks it as a target.
  - A repeating beacon beep plays while a target is locked.
  - Press W to hear the direction (e.g. "straight in front", "slightly to the left") and distance to the target.
  - Press T again or arrive at the target to cancel tracking.
  - Removed WASD movement to free up W for the "Where is target?" command.

Version 0.1.2
  - Added zone system for named map areas (zone::minx:miny:minz:maxx:maxy:maxz:name).
  - Press B to read your current zone/location.
  - Added named labels to map objects for better tracking announcements.

Version 0.1.1
  - Fixed game startup on file:// protocol by adding a hardcoded map fallback.
  - Added distinct collision thud sound so you can hear when you hit a wall.
  - Added Escape key to exit the world and return to the main menu.
  - Added e.preventDefault() to world movement to stop page scrolling.

Version 0.1.0
  - Implemented smooth exponential music fade-out for transitions.
  - Upgraded step sounds using bandpass filters for realistic tile footsteps.
  - Added Player entity to MapEngine with AABB collision detection.
  - "Start Game" now loads the reception map and enters a walking mode.
  - WASD/Arrow keys control the player in the world.

Version 0.0.9
  - Upgraded Map Engine to full 3D (added minz/maxz coordinates).
  - X is Left/Right, Y is Back/Forward, Z is Up/Down (stairs/elevation).
  - Added block-based object parser for the .map format.
  - Created a highly advanced reception.map with walls, furniture, stairs, doors, and an NPC.

Version 0.0.8
  - Fixed radio button hint timer: it no longer nags you after you already use the left/right arrow keys.

Version 0.0.7
  - Added inactivity hint for radio buttons ("Press left and right arrow keys to change" after 2s).
  - Initial work on data-driven Map Engine (MapEngine).
  - Added .map file parser (no ASCII, purely key-value headers and object placeholders).
  - Created first map: maps/reception.map.

Version 0.0.6
  - Added radio button widget for settings with Left/Right arrow key support.
  - Added 2-finger swipe support for Android to change radio options without triggering back gestures.
  - Hidden Speech settings from the main Options menu on Android.
  - Refactored Speech menu to use the new radio button widget.

Version 0.0.5
  - Added Speech settings menu to choose between Screen Reader and Browser TTS.
  - Hidden Screen Reader option on Android (since TalkBack must be disabled to play).
  - Increased menu TTS speech rate to 1.2x and reduced interrupt delay for snappier navigation.
  - Settings are now saved to localStorage.

Version 0.0.4
  - Added NVDA/screen reader support via ARIA live regions.
  - Added TTS interrupt flag to prevent speech overlap.
  - Menu items no longer announce their position number unless Space is pressed to repeat.
  - Fixed options menu speech queue issues.

Version 0.0.3
  - Built the audio menu system with keyboard navigation (Up/Down, Enter, Escape, Space, Home/End).

Version 0.0.2
  - Created the procedural sound bank (DSP) — all sounds generated via Web Audio API, no audio files.

Version 0.0.1
  - Made a basic index.html to support the webview for the game.

Version 0.0.0
  - Set up GitHub repo and doing tasks in the background.
